# Delivery Device

- **Жанр**: Симулятор
- **Платформа**: ПК (Windows)
- **Игровой движок**: Unreal Engine 5 (C++/Blueprint)

## Описание

Delivery Device - игра, разработанная на гейм-джеме, проводимого ВШЭ. Игрок является роботом-курьером, ему необходимо выполнить цепочку заданий для победы. 

Тема гейм-джема: **Зимний киберпанк**

## Геймплей и механики

Игрок начинает в гараже, где он обучается управлению. После он берет первое задание и едет к назначенной точке.

На пути игрока есть несколько препятствий:
- Снег (плохая видимость)
- Сугробы (препятствия, которые необходимо толкать)
- Метель (по карте "гуляет" сильный ветер, который толкает робота-курьера с большой силой)
- Лёд (очень скользкий лёд, из-за которого теряется сцепление с дорогой)

Все грузы имеют параметр здоровья и игрок должен привести его невредимым.

Также задания имеют модификаторы:
- Тяжелый груз
- На время (например, доставка пиццы)
- Случайное подергивание (например, доставка животного)

![Cargo health](https://github.com/CubeRuben/CubeRuben/blob/c221789ad948e60e1013984efcede5c73a743851/game-jam-2024-00/task.gif?raw=true)

После того, как игрок доставил груз, он получает награду в виде денег, которые он может потратить на улучшения в гараже (Улучшения не реализованы).

Вся карта покрыта снегом, который деформируется под роботом-доставщиком.
